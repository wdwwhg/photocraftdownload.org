## New-release update checklist

1. Read upstream release notes and compare assets before changing the manifest.
2. Re-run metadata, checksums and download response verification; keep the tag and timestamp.
3. Update the historical archive with verified changes and every reviewed file.
4. Run the relevant platform and sample-document acceptance steps; keep old captures labelled with their original version.
5. Publish the tested content and measure new impressions/clicks. Discuss a release in communities only when relevant to an existing question or permitted by that community's rules.
