# PhotoCraft download site release — 23 October 2026

## User-visible changes

The download page now presents the reviewed files in initial HTML: operating system, CPU architecture, installation format, official direct link, exact file size and full SHA256. The interactive chooser remains available as an optional helper.

Windows, macOS and Linux guides expose the same verified file data. The Windows heading and Windows 11 architecture guidance are more direct. The Linux page identifies itself as a documentation-based build reference with a distribution matrix; it does not claim unrecorded Linux execution tests.

The version archive is indexable again and includes version anchors, dates, source-linked changes and file records for the reviewed historical releases. Safety and installation troubleshooting pages connect the platform guides with verification commands and diagnostics. The safety page publishes the actual Microsoft Defender result for one Windows x64 MSI, with its exact file hash, engine and signature versions and original output.

The site keeps the reviewed v0.9.0 downloads and their original test labels. A visible notice links to the newer official release. New-version monitoring remains enabled and may report an update due independently of a successful site deployment.

## Search structure

The sitemap contains 18 English URLs. Existing Chinese pages remain available with noindex where retained. Four retired topics return 404 in both existing languages: lightcraft, vectorcraft, photocraft-vs-vectorcraft and photocraft-web. Their remaining article links now lead to the appropriate official product/documentation or the expanded alternatives section. No Search Console validation or indexing request is submitted by this release.
