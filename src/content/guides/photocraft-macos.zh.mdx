Mac 安装最容易卡在两个地方：把 CLI ZIP 当成桌面应用，以及把所有安全提示当成同一种错误。本文说明 **PhotoCraft v%CURRENT_VERSION%** 的安装与 Gatekeeper 排查。

**当前官方 README 把 DMG 标注为已签名并公证。** 先使用官方 DMG 正常安装。若你使用旧版或自行编译的未签名版本，遇到拦截时按下面对应分支处理。

## Intel 与 Apple 芯片下载同一个 DMG

打开 **苹果菜单 → 关于本机**：“芯片 Apple M…”表示 Apple 芯片，“处理器 Intel…”表示 Intel。两者都使用[官方 Universal DMG](https://github.com/storytold/photocraft/releases/download/v%CURRENT_VERSION%/photocraft-%CURRENT_VERSION%-macos-universal.dmg)。

文件名是 **photocraft-%CURRENT_VERSION%-macos-universal.dmg**。photocraft-cli 开头的 ZIP 是命令行工具，不能代替桌面版安装。也可以回到[三步下载选择器](/#downloads)确认。

## 从 DMG 安装到应用程序

1. 下载完成后打开 DMG，将 **PhotoCraft** 拖到“应用程序”文件夹，等待复制完成。
2. 从“应用程序”启动复制后的应用。不要一直从下载目录或挂载的磁盘映像启动；复制完成后可在 Finder 侧边栏推出磁盘映像。
3. 如果只是“从互联网下载的应用，确定打开吗”的首次确认，核实是刚下载的应用后选择“打开”。

遇到错误，先记下弹窗原文，再按下表分流。详细依据见 [Apple 安全打开应用说明](https://support.apple.com/en-us/102445)。

| 提示类型                                        | 意味着什么                   | 看哪一步                     |
| ----------------------------------------------- | ---------------------------- | ---------------------------- |
| 从互联网下载，是否打开                          | 首次启动确认                 | 正常安装步骤                 |
| 无法验证开发者 / Apple 无法检查是否包含恶意软件 | 来源或公证未被系统确认       | 下节的单应用放行             |
| App 已损坏，无法打开                            | 可能损坏、被改动或校验不通过 | 重新下载与完整性检查         |
| 将损坏你的电脑 / 检测到恶意软件                 | 不是普通的未签名提示         | 停止启动，获取开发者修复版本 |

## 无法验证开发者时怎样打开

适用于你已经核实来源、确认要运行的未签名或未公证应用：

1. 先在“应用程序”里尝试打开一次，让系统生成该应用的拦截记录。
2. 打开 **系统设置 → 隐私与安全性**，向下找到“安全性”中的对应应用提示。
3. 选择 **仍要打开（Open Anyway）**；部分系统还需先点“打开”，再选择“仍要打开”。输入登录密码或按系统要求认证，确认这一次打开。

[Apple 的分步说明](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)指出，按钮通常在尝试启动后一小时内可用。没有按钮时先重新尝试打开一次，再检查设置；受管理的 Mac 可能由组织限制。不同 macOS 版本的文字会变化，不应把“右键打开”写成所有版本都有效的唯一办法。

这是**只为该应用添加例外**。无需为了安装 PhotoCraft 关闭整台 Mac 的 Gatekeeper。

## 提示 App 已损坏怎么办

“已损坏”并不等同于“只是没签名”。按顺序缩小问题：

1. 退出应用；将有问题的应用副本移到废纸篓，保留自己的项目文件。不要把新版本覆盖进一个可能不完整的旧应用包。
2. 从同一官方版本重新下载 DMG，比较 SHA-256。以下命令以文件在“下载”目录为例：

```sh
shasum -a 256 "$HOME/Downloads/photocraft-%CURRENT_VERSION%-macos-universal.dmg"
```

3. 与[同版本 SHA256SUMS.txt](https://github.com/storytold/photocraft/releases/download/v%CURRENT_VERSION%/SHA256SUMS.txt) 中该 DMG 的完整值比较。不一致时重新下载；一致后重新挂载 DMG，完整复制到“应用程序”再试。
4. 若仍然失败，记录 macOS 版本、弹窗原文和下节检查结果，提交给[官方维护者](/photocraft-github)。

移除隔离标记或临时重签名都不会修复一个已经损坏的文件，也会丢失诊断线索；这里的处理顺序是先验证和重装。出现“恶意软件”或“将损坏电脑”时，不把它套进“仍要打开”的步骤。

## 进一步检查签名与启动问题

愿意使用终端的用户，可以对**已经复制到应用程序里的应用**执行只读检查：

```sh
codesign --verify --deep --strict --verbose=2 "/Applications/PhotoCraft.app"
spctl --assess --type execute --verbose=4 "/Applications/PhotoCraft.app"
```

如果实际名称不同，把 Finder 中的应用拖入终端以得到真实路径。前者验证签名结构，后者请求系统评估；这两条命令不会移除隔离标记或修改签名，也不是对软件功能和所有安全风险的保证。签名失败时不要靠重新签名把报错“变绿”。

应用打开后空白画布或闪退，属于启动或图形问题，不应继续改 Gatekeeper 设置。查看 Help → System Info；官方默认日志路径为 ~/Library/Application Support/Photocraft/logs。先用图片副本试一次打开、保存与导出，再进入[入门教程](/photocraft-tutorial)。

## 更新与卸载

更新前退出应用，保留工作文档与需要的设置备份，再用新 DMG 中的应用替换“应用程序”里的旧版。移走 App 不等于删除项目文档，也不必为了卸载清空整个用户资料库。
