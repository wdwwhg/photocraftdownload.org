LightCraft is ArtCraft's photo-library and raw-development application. Its role is organizing photographs and developing their appearance while retaining the original files. That differs from building a layered composite in [PhotoCraft](/photocraft-app), even though both applications work with photographs.

This introduction follows official documentation checked October 12, 2026. Camera support and output behavior should be confirmed with your own files before adopting a new photo workflow.

## Library and non-destructive development

The [official LightCraft page](https://getartcraft.com/apps/lightcraft) describes albums, ratings, flags, search, adjustment controls and masks. It presents a non-destructive development pipeline and lists several raw-format families, including DNG, CR2, ARW and NEF.

A format family is not a complete list of supported camera models. Two cameras can produce files with the same extension but different details. Choose samples from the camera, firmware and recording mode you actually use.

A non-destructive workflow also benefits from backups. Preserving original pixels does not make a catalog, edit database or external storage immune to accidental changes. Keep originals and working records in a backup plan appropriate to their importance.

## Official downloads and version

The product page supplies standalone desktop builds and an ArtCraft Launcher option. On October 12, 2026 the listed release was **LightCraft 0.6.0**, with Windows, macOS and Linux options.

- [Official LightCraft product and download page](https://getartcraft.com/apps/lightcraft)
- [LightCraft source repository](https://github.com/storytold/lightcraft)
- [Latest official release](https://github.com/storytold/lightcraft/releases/latest)

Use the current official links to select a package for your system and processor. An existing PhotoCraft installation does not mean LightCraft is already installed: each is a separate application. If you use the launcher, check the specific product and version it is installing.

## Evaluate a small photo collection

Begin with a copied folder containing a few representative images: a normal exposure, a high-contrast scene and a photograph with skin tones or colors you know well. Include a JPEG reference if your camera can produce one alongside its raw file.

Import the sample, organize it with the available library controls and apply a modest exposure or color adjustment. Close and reopen the application to check that the organization and edits persist as expected.

Export one image and view it outside the editor. Check dimensions, appearance and the intended color-space handling. Keep your raw original, the application's editing records and the export conceptually separate so you know which one is needed for a later revision.

## RAW and color checks

Start by confirming that your exact raw file opens without an error. Then inspect orientation, cropping, highlight detail and obvious color differences. A successful decode is only the first step in assessing a photographic workflow.

If you need a specific input profile, lens correction or delivery color space, verify it in the current documentation and test the resulting file. Do not infer complete Lightroom parity from a similar panel arrangement or the phrase raw development.

When a file behaves unexpectedly, document the camera model, format, application version and the operation that caused the difference. Share a non-private sample only when needed to reproduce the issue in the [official repository](https://github.com/storytold/lightcraft).

## LightCraft and PhotoCraft together

Use a library-and-development tool to assess a collection and prepare an image's overall appearance. Use an image editor when the next task requires composition, text or detailed layer work. Choose a mutually supported export format and inspect the transition.

The [PhotoCraft app guide](/photocraft-app) covers a first layered edit. If you are choosing between several general image editors, see the [alternatives guide](/photocraft-alternative). For vector design or video work, the separate family guides cover [VectorCraft](/vectorcraft) and [FilmCraft](/filmcraft).

## Decide with a complete round trip

A useful adoption check covers import, organization, editing, reopening and export. Completing only the first step will not reveal whether your finished delivery meets requirements. Record the tested version and repeat affected checks when a release changes your workflow.

This page reports the product's documented role and proposes evaluation steps. It does not claim that all cameras, lens profiles or existing Lightroom catalogs are compatible.
