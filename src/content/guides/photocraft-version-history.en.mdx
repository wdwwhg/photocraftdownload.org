## Before updating or rolling back

1. **Keep a working-document copy.** Quit before replacing the application, then test opening, saving, exporting and reopening a copy.
2. **Use a complete package for the chosen version.** Avoid mixing executables, supporting files and portable settings from different releases.
3. **Check backward file compatibility.** An older build may not fully read a project saved by a newer one, especially after using a new feature. Preserve the earlier original.
4. **Record the version and error.** Compare the same copied file, then follow the [issue-reporting guide](/photocraft-github).

Use the [Windows](/photocraft-windows), [macOS](/photocraft-macos) or [Linux installation guide](/photocraft-linux) for setup. Those guides use the site's currently reviewed version; older releases need their own filenames and requirements.
