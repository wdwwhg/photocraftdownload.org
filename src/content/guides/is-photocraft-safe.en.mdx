PhotoCraft has an open-source repository and official release downloads, but those facts alone do not prove every file is safe. Start with the exact release, verify its hash and review your operating system's security result before running it. **Our Microsoft Defender scan found no threats in one v0.9.0 Windows x64 MSI on 23 October 2026.** Other packages and later releases are outside that scan's scope.

## What we can verify

Our [download table](/#downloads) links to the **storytold/photocraft** GitHub release assets. It shows the file size in bytes and MiB, and the full SHA256 from that release's official checksum file. The current metadata check compares those values with GitHub asset digests where available and checks each download response. It does not download and scan installer contents.

The site's reviewed downloads and [Windows document test](/photocraft-windows#our-portable-launch-and-document-check) cover **v0.9.0**. Later releases have their own files and hashes. Check the [official latest release](https://github.com/storytold/photocraft/releases/latest) for newer versions and the [version archive](/photocraft-version-history) for reviewed older files.

| Evidence                                    | What it establishes                                | What it cannot establish                              |
| ------------------------------------------- | -------------------------------------------------- | ----------------------------------------------------- |
| SHA256 matches the published value          | Your bytes match the published file fingerprint    | Whether the publisher's file is harmless              |
| File size and download response             | The listed asset is present and responds as a file | Its behavior after installation                       |
| GitHub digest agrees with the checksum list | Two upstream records identify the same hash        | An independent security review                        |
| Recorded Windows portable exercise          | One editing workflow ran on our recorded machine   | Every installer, operating system or document is safe |

## Windows SHA256 verification

In PowerShell, from the folder containing the downloaded file:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\photocraft-0.9.0-windows-x64.msi'
```

Compare **all 64 hexadecimal characters** in `Hash` with the same filename in the [Windows download table](/photocraft-windows#photocraft-windows-download-files) and [v0.9.0 SHA256SUMS.txt](https://github.com/storytold/photocraft/releases/download/v0.9.0/SHA256SUMS.txt). Letter case does not matter. For Portable ZIP, x86 or ARM64, substitute that exact filename; its hash will differ.

## macOS SHA256 verification

In Terminal, from the download directory:

```sh
shasum -a 256 photocraft-0.9.0-macos-universal.dmg
```

Match the result to the DMG row on the [macOS download page](/photocraft-macos#one-dmg-for-intel-and-apple-silicon). A matching hash and Gatekeeper approval answer different questions. Apple documents signature, notarization and first-launch alerts in its [safe-opening guidance](https://support.apple.com/en-us/102445). We have no local macOS scan or Gatekeeper test result.

## Linux SHA256 verification

For an AppImage downloaded into the current directory:

```sh
sha256sum photocraft-0.9.0-linux-x86_64.AppImage
```

Use the [Linux file table](/photocraft-linux#official-files-and-checksums) to select the exact architecture and format. A Flatpak bundle, DEB, RPM and tar.gz each have a different hash. Verify before executing the AppImage or installing a package.

To check a single file using the official checksum list, keep that exact list and the download in one directory:

```sh
sha256sum --ignore-missing --check SHA256SUMS.txt
```

Confirm that the output names **your intended file** and reports `OK`. This also checks any other files from that checksum list present in the same directory; it does not imply the missing downloads were checked. The checksum list must come from the same release as the file.

## If a hash or warning does not match

Stop before running the file. Check release, architecture and filename first; then obtain a fresh copy through the exact official release. If a mismatch persists, report the expected and actual SHA256 to the project. For SmartScreen, Gatekeeper, MSI errors or FUSE failures, follow [PhotoCraft installer not working](/photocraft-installer-not-working). Do not disable protection simply to make a warning disappear.
