## 本站 Windows 实拍与操作记录

**拍摄日期：2026-10-15（UTC+8）。** 应用为官方 `photocraft-0.9.0-windows-x64-portable.zip`，应用内版本显示 **0.9.0（c699e3cda，2026-10-14）**。系统为 Windows 11 25H2（26200.9711）、x64，显卡 NVIDIA GeForce RTX 4060 Laptop GPU，应用内显示 Vulkan 后端。界面语言为中文；下方保留应用窗口、菜单、文件名和实际对话框。

我们下载了[官方 v0.9.0 便携包](https://github.com/storytold/photocraft/releases/tag/v0.9.0)，本地 SHA-256 与[官方校验清单](https://github.com/storytold/photocraft/releases/download/v0.9.0/SHA256SUMS.txt)一致。完整文件名、校验值与截图原图摘要保存在[本次拍摄记录](/imgs/photocraft/captures/capture-record.json)。

这次实际执行的步骤：

1. 打开本站原创的 1200 × 800 PNG 测试画布。画布上的 COAST 文字与图形在导入前已栅格化，未作为可编辑文字测试。
2. 复制像素图层，添加一个色阶调整图层，把 RGB 中间调设为 **1.10**。
3. 另存为 `coast-layers.psd`，关闭文档，再从最近文件重新打开。
4. 检查 `Layer 0`、`Layer 0 copy`、`Levels 1` 三个图层仍在，选择色阶图层后，参数仍显示 **1.1**。
5. 从“帮助”打开“关于 PhotoCraft”和“系统信息”，拍摄原始窗口。

## 文档支持哪些结论

README 列出像素图层、蒙版、调整层、可编辑文字、形状、图层样式与智能对象，支持 PSD、PSB、原生 .pcraft 和多种图片导出。这说明相关功能已提供，但不能证明每种文件都完全兼容。项目也提醒，提供相似的菜单命令不代表操作结果与 Photoshop 完全一致。

Rust、egui 和 wgpu 说明实现方式，不足以单独证明你的设备上更快、更省内存或更稳定。

## 适合谁先尝试

个人小型合成可以从一张照片、标题和调整层开始，参见[教程](/photocraft-tutorial)。开发者可通过 [Rust 指南](/photocraft-rust)了解源码与自动化。

客户项目、严格截止日期、复杂字体、插件或高位深色彩工作流，应先用副本并行测试。失败保存或交接变化的代价，比功能数量更影响采用决定。

## 优点与待验证项

| 领域     | 文档依据             | 自测重点           |
| -------- | -------------------- | ------------------ |
| 编辑模型 | 图层、蒙版、实时调整 | 重开后仍可编辑     |
| PSD      | 读取、修改和保存     | 字体、效果与交接   |
| 交付     | 桌面包与网页构建     | 本机安装和图形行为 |
| 源码     | 公共 Rust 仓库与授权 | 固定版本构建       |
| 自动化   | 命令接口             | 所需操作与集成边界 |

README 的测试语料结果属于项目方报告，本网站未复现。语料测试不能转换为“所有 PSD 均字节相同”或“所有文件视觉无损”的承诺。

## 重要限制

v0.8.2 状态说明指出 AI 与生成式功能、文字排版深度、专业流程和插件兼容方面的缺口。熟悉的界面不足以保证全面替代 Adobe，参见[Photoshop 对比](/photocraft-vs-photoshop)。

浏览器版另有保存下载文件、缺少网页自动保存与崩溃恢复等限制，参见[网页版说明](/photocraft-web)。

## 按实际文件评估

记录应用版本、系统与图形环境。先打开小文档副本，保存并重开；再创建独立调整和文字，导出并在其他查看器检查。

接着选择真实任务的代表文件，提前列出蒙版、混合模式、字体、智能对象、效果、位深和外部依赖。与原始应用参考图比较，另存新文件，按交接需求在两个应用重开。

最后检查恢复预期，记录失败步骤，保留源文件与备份。结论应限定为“这个版本已验证的这些任务”，不能扩大为普遍替代承诺。

## 采用建议

先用于学习、实验和边界明确的任务；生产采用依据自身文件测试结果。必须功能缺失时查看[替代方案](/photocraft-alternative)，并通过 [GitHub 指南](/photocraft-github)提交最小复现。
