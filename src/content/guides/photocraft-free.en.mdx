PhotoCraft is presented by its official project as a free, open-source image editor. Its public repository identifies the software license as MIT OR Apache-2.0, and official releases provide packaged downloads. For this project, “free” refers to the editor's availability; it should not be interpreted as a promise that every asset, hosted service or operating cost in an editing workflow is free.

This guide answers the availability question. For the actual packages, use [PhotoCraft Download](/). For license texts and contributions, use [PhotoCraft Open Source](/photocraft-open-source). For whether the editor fits your work, use the [PhotoCraft review](/photocraft-review).

## Free application, not just source access

GitHub contains both the source tree and release assets. A user who wants to edit images can select a ready-made package rather than compiling the repository. The automatically generated source archives serve a different purpose and may not contain an executable to run.

The official product page and repository describe the application as free and open source. We do not present it as a timed trial or invent a premium tier. If an unrelated download site asks for payment, compare its offer with the official release and confirm whether it is selling a separate service, repackaging or a different product with the same name.

## What the software license covers

The MIT and Apache-2.0 texts govern the project's software under their respective terms. Source access lets you inspect the implementation and, within the applicable terms, work with the code. It does not eliminate the need to preserve required notices when distributing software or to check the licenses of dependencies and bundled materials.

This page is an availability guide rather than a legal interpretation of a distribution arrangement. For modified builds or organizational redistribution, read the actual license files and identify every component being distributed. A statement that an app is open source is not a complete inventory of the rights attached to all material inside a custom package.

## Costs outside the editor

| Item                    | What to check                                         |
| ----------------------- | ----------------------------------------------------- |
| PhotoCraft package      | Use official release links and version notes          |
| Photographs and artwork | Confirm ownership or permission for the intended use  |
| Fonts                   | Check desktop use, embedding and redistribution terms |
| Web hosting             | Check the host's plan, limits and operating costs     |
| External integrations   | Read the separate provider's terms and pricing        |
| Support or training     | Distinguish independent paid services from the editor |

For example, a free editor can open a project containing a separately licensed typeface. That does not let you redistribute the typeface with a hosted browser build. Likewise, self-hosting the web version may involve a domain or hosting plan even when the editor's files are freely available.

Do not infer that an external AI provider, plugin or commercial asset library shares PhotoCraft's terms. Evaluate those items separately when planning a workflow. The cost of running your own hardware or maintaining a deployment is also distinct from the download price.

## Does free mean ready for professional work?

No pricing label establishes reliability or compatibility. PhotoCraft v0.8.2 identifies itself as early alpha and explicitly cautions against treating it as a daily professional Photoshop replacement. That limitation applies even when the software costs nothing to download.

Test the required tasks on copies of your own files. Start with opening, saving, reopening and exporting. If the workflow depends on PSD effects, fonts or plugins, use the [Photoshop comparison checklist](/photocraft-vs-photoshop). A failed handoff can cost more time than a download saves, so suitability should be checked separately from price.

## Obtain it without confusing the packages

Confirm that the project is the ArtCraft image editor and that the repository is storytold/photocraft. Select the release package for your operating system and processor. For Windows, distinguish the MSI installer from the portable ZIP; for the web version, distinguish the static site archive from an already-hosted service.

The [GitHub guide](/photocraft-github) walks through source and release navigation. The [web guide](/photocraft-web) explains hosting and browser save behavior. If you only need a desktop editing session, there is no reason to begin by provisioning a web host or installing a Rust toolchain.

## A simple decision before downloading

Write down the task, the package you need and any outside materials required to complete it. Confirm the official download, then check those outside materials independently. Keep the initial test small and retain originals. This separates three useful answers: the editor is available free, its software has documented open-source terms, and your complete workflow still needs its own compatibility and rights checks.
