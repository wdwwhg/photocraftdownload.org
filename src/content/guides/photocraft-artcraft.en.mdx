PhotoCraft is the image-editing application presented within the ArtCraft family of creative tools. ArtCraft is the broader identity used by the official site and community; it is not another name for the PhotoCraft executable. Searching “ArtCraft PhotoCraft” or “PhotoCraft ArtCraft” points to the same relationship, so this page explains both word orders together.

The official links are [getartcraft.com/apps/photocraft](https://getartcraft.com/apps/photocraft) for the product and [github.com/storytold/photocraft](https://github.com/storytold/photocraft) for its source. This website is an independent download and documentation guide. It does not operate the ArtCraft project or represent its maintainers.

## Understand the names

| Name                 | Role                          | What you get                                 |
| -------------------- | ----------------------------- | -------------------------------------------- |
| ArtCraft             | Family and community identity | Product directory and community entry points |
| PhotoCraft           | Image-editing application     | Layers, masks, type and photo-editing tools  |
| ArtCraft Launcher    | Application manager           | A way to install and manage Crafting Apps    |
| storytold/photocraft | GitHub repository             | Source, versioned documentation and releases |

These names describe different parts of the same ecosystem. A launcher installation is not the same artifact as a standalone PhotoCraft package. A repository owner is an identifier for finding source, not enough information to infer a company's legal structure, trademark ownership or corporate history. Use the official project's own statements for any such question.

## How the sibling apps differ

The official product directory groups several creative applications under the Crafting Apps name. The applications have different tasks rather than being editions of PhotoCraft. VectorCraft concerns vector illustration, FilmCraft concerns video editing, and LightCraft concerns photo organization and RAW-related workflows.

For a logo, compare [PhotoCraft and VectorCraft](/photocraft-vs-vectorcraft). For a timeline project, read the [FilmCraft guide](/filmcraft). For managing a photo collection, start with [LightCraft](/lightcraft). The fact that a task involves images does not mean the image editor is always the right first tool.

Keep files associated with the application that created them. Sharing a family identity does not prove that every project format, filter or plugin moves between sibling applications without changes. Test a small interchange file and keep the original source document when crossing applications.

## Standalone app or launcher?

Choose a standalone PhotoCraft package when you want the image editor alone and prefer to select its release directly. The [download page](/) links to official packages and distinguishes their platforms. The ArtCraft Launcher is presented as a way to manage multiple applications from the family.

Before installing through a launcher, check which application and version it will install. Before installing a standalone package, check the operating system and processor architecture. These checks address different questions: one establishes product identity, and the other establishes package suitability. Neither requires compiling Rust when you select a ready-made PhotoCraft release.

## Relationship to Adobe

PhotoCraft uses familiar image-editing concepts and describes its project in relation to Photoshop workflows. Its v0.8.2 README explicitly states that the independent project is not affiliated with, sponsored by or endorsed by Adobe. Photoshop references explain intended workflows and compatibility; they do not indicate Adobe ownership or an official Adobe edition.

The [PhotoCraft vs Photoshop guide](/photocraft-vs-photoshop) evaluates that practical comparison. It also separates familiar interface concepts from proof that a production document, plugin or color workflow will behave identically.

## Verify a result with a similar name

Search results can include unrelated software, image services or research using similar names. Check the product URL, the repository owner and the feature description together. A result for a separate service should not inherit this project's download links, license or release status just because its title contains PhotoCraft.

For a specific version, use the matching tagged documentation in GitHub. Product pages can be updated on a different schedule from release assets. If the displayed versions disagree, read the release notes rather than inventing a connection between packages. Continue to the [GitHub guide](/photocraft-github) for release-versus-source navigation or [What Is PhotoCraft?](/what-is-photocraft) for the editor's capabilities and limits.
