PhotoCraft 是 ArtCraft 创作应用家族中的图像编辑器。ArtCraft 是应用家族的名称，PhotoCraft 是其中的一款应用；ArtCraft Launcher 则是用于安装和管理这些应用的启动器。

本网站是独立下载与文档指南，不代表或运营 ArtCraft 项目。官方产品入口为 [getartcraft.com/apps/photocraft](https://getartcraft.com/apps/photocraft)，源码入口为 [storytold/photocraft](https://github.com/storytold/photocraft)。

## 名称分别指什么

| 名称                 | 角色                           |
| -------------------- | ------------------------------ |
| ArtCraft             | 应用家族与社区身份             |
| PhotoCraft           | 图层、蒙版、文字与照片编辑应用 |
| ArtCraft Launcher    | 管理多个家族应用的工具         |
| storytold/photocraft | 源码、文档与发布仓库           |

启动器与独立安装包是不同交付物。仓库所有者只是寻找源码的标识，不能据此推断公司的法律结构、商标权或历史。

## 同系列应用的差别

官方目录中的应用有不同任务，并非 PhotoCraft 的不同版本。VectorCraft 面向矢量插画，FilmCraft 面向视频剪辑，LightCraft 面向照片整理和 RAW 工作流。

绘制标志可看[VectorCraft 对比](/photocraft-alternative#choose-raster-vector-or-raw-work)，时间线项目看 [FilmCraft 指南](/filmcraft)，整理照片看 [LightCraft 指南](https://getartcraft.com/apps/lightcraft)。共享品牌不证明文件、滤镜或插件可以完全互换；跨应用交接应保留源文件并测试小样。

## 独立应用还是启动器

只需图像编辑器、希望直接选择版本时，使用独立 PhotoCraft 包。[下载页](/)按平台整理官方资产。需要管理多个家族应用时，可查看官方 Launcher 说明。

通过启动器安装前确认应用和版本，下载独立包时确认系统与架构。选择现成包不需要自行编译 Rust。

## 与 Adobe 的关系

PhotoCraft 使用熟悉的图像编辑概念，并参考 Photoshop 工作流。v0.8.2 README 明确说明项目独立，与 Adobe 没有关联、赞助或背书。兼容性描述不代表 Adobe 官方产品。实际交接边界参见[Photoshop 对比](/photocraft-vs-photoshop)。

## 排除同名产品

同时检查产品域名、仓库所有者和功能描述，不要将其他同名服务的授权或下载方式套用到此项目。针对具体安装版本应阅读对应标签文档；产品页和发布资产的更新节奏可能不同。版本显示不一致时核对发布记录。

源码获取参见 [GitHub 指南](/photocraft-github)，功能介绍参见 [PhotoCraft 是什么](/what-is-photocraft)。
