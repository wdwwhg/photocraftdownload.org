This exercise reproduces the small editing sequence in our **23 October 2026 Windows test**. It uses original artwork and an inspectable saved file, so you can check the outcome instead of guessing from a feature list. Allow time to inspect the layers after saving; creating a file alone is not the final check.

Our recorded environment was PhotoCraft **0.14.0**, Windows 11 25H2 x64, the x64 portable package, an RTX 4060 Laptop GPU and DX12. The actual application UI in our screenshots is Chinese. English menu labels below describe the same editing concepts; wording can vary by UI language. We have not repeated this exercise on macOS or Linux.

## Download the practice files

1. Obtain the desktop package from the [download page](/#downloads). The [Windows guide](/photocraft-windows) explains complete ZIP extraction and architecture selection.
2. Download our [1200 × 800 practice PNG](/imgs/photocraft/captures/coast-test.png) to a practice folder. Our artwork is provided under CC0.
3. Keep the [reference PSD](/imgs/photocraft/captures/coast-layers-0.14.0.psd) in that folder under a distinct name. It is the result to inspect, not the input for the first run.

The word COAST is already rasterized into the PNG. This exercise does not create or test editable text. The [SVG source](/imgs/photocraft/captures/coast-test.svg) is available to inspect the original artwork, but use the PNG for this sequence.

## Open the PNG and duplicate its layer

Use **File → Open** and choose the PNG. Confirm a 1200 × 800 document and identify the pixel layer in the Layers panel. Our imported layer was named **Layer 0**.

Select that layer and use the layer duplication command. In our result, the duplicate is **Layer 0 copy**. Before continuing, count two pixel layers. If you see a different document or only one layer, correct that now rather than adding adjustments to the reference PSD by mistake.

## Add Levels at midtone 1.10

With the working document active, create a **Levels adjustment layer**, keeping it separate from the pixel layers. Our resulting layer is named **Levels 1**. Select its adjustment thumbnail to inspect the Levels controls.

Choose the **RGB** channel and set the middle input value to **1.10**. Leave the other values at their defaults for this exercise. The screenshot displays **1.1**, which is the same numerical value. Count three layers: two pixel layers and the Levels adjustment.

Applying Levels directly to a pixel layer would produce a different document structure. If no Levels layer appears, undo and create the separate adjustment before saving.

## Save, close and reopen the PSD

1. Save the working document as **coast-practice.psd** in your practice folder. Keep the input PNG and reference PSD intact.
2. Close the document after saving.
3. Reopen your saved PSD through File → Open or Recent Files. Our v0.14.0 run reopened it through File → Open.
4. Confirm that there are still three layers.
5. Select the Levels adjustment thumbnail and check that RGB midtone still reads **1.1** or **1.10**.

The original test saved as coast-layers-0.14.0.psd; your different filename keeps your output separate from our reference. A flat PNG export cannot pass the layer check because it does not preserve an editable layer stack.

## Diagnose a different result

If the Layers panel is hidden, show it before comparing the stack. If Levels controls are absent, select the adjustment thumbnail rather than a pixel layer or its mask. If the file reopened flat, confirm the saved extension and whether you used a flattened export.

If a difference persists, record the installed version from **Help → About** and the graphics backend from **Help → System Info**. Include the exact failing step and a copy of this public sample in a [reproducible issue report](/photocraft-github). The sample avoids having to share a private project to demonstrate the same basic failure.

## What to test next

After the small exercise succeeds, use a duplicate of one real project. Add separate checks for editable type, masks, effects and any required export. Saving the sample above does not verify those features. For an Adobe handoff, open the PSD in the recipient's Photoshop version as well; follow the [comparison checklist](/photocraft-vs-photoshop).

A PNG or JPEG export is useful as a viewing copy, but keep the editable document for revisions. Export and cross-application rendering are follow-up checks, not results recorded in this exercise.
