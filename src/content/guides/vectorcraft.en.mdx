VectorCraft is ArtCraft's application for vector illustration. Its focus is artwork made from paths, shapes and text: useful building blocks for a logo, icon, diagram or poster. This page covers that role, the official installation routes and a small exercise to evaluate it.

For editing photographic pixels and layered image compositions, see the [PhotoCraft app guide](/photocraft-app). Choosing between the two begins with the structure of the artwork you need to keep editable.

## What the project documents

The [official VectorCraft page](https://getartcraft.com/apps/vectorcraft) describes pen and direct-selection tools, shape operations, snapping guides, an appearance panel and editable effects. It lists SVG and PDF import and export alongside raster output formats. These are developer descriptions, not an independent compatibility certification.

A vector workflow lets you revise a path or shape separately from the final rendered image. When evaluating it, check whether the parts you need remain editable after saving and reopening. An exported image that looks correct does not by itself demonstrate that the underlying document is suitable for later revisions.

## Official downloads and source

The product page offers standalone builds for Windows, macOS and Linux, as well as an ArtCraft Launcher option. On our October 12, 2026 review, it listed **VectorCraft 0.14.0**. Use its current links when selecting a newer version.

- [Official VectorCraft product and download page](https://getartcraft.com/apps/vectorcraft)
- [VectorCraft source repository](https://github.com/storytold/vectorcraft)

Select the package for your operating system and CPU. A source-code archive is intended for building the program, whereas an installer or packaged application is intended for use. The launcher is convenient when you plan to manage several Crafting Apps; a standalone installation is sufficient to evaluate this one.

## A first vector project

Start with a small icon or badge. Create a few shapes, adjust their order and combine two shapes with a boolean operation. Add a short text label. Change a fill and stroke independently so you can see how appearance settings relate to the object.

Save an editable working document before exporting. Reopen that document and move one point or revise the label. This checks the part of a vector workflow that a final screenshot cannot show: whether future changes remain straightforward.

Export an SVG for another vector tool and a PNG for simple viewing. Compare both at the intended output size. If a receiving application is part of your workflow, open the SVG there and inspect text, clipping and effects.

## SVG and PDF handoff checks

Format support is a starting point. Fonts, clipping, effects and application-specific features still deserve a check with a representative file. Include a reference image when handing off editable artwork so the recipient can compare the intended appearance.

For a print job, ask the printer for its output requirements before choosing an export. For an icon set, check alignment and appearance at the actual display sizes. Those delivery requirements are more useful acceptance criteria than whether the application resembles another editor.

If an import fails, preserve the original and reduce a copy to the smallest example that reproduces the problem. Report the build version and source format in the [official repository](https://github.com/storytold/vectorcraft).

## Where it fits in the ArtCraft family

Use VectorCraft to investigate vector artwork, [PhotoCraft](/photocraft-app) for image editing, [LightCraft](https://getartcraft.com/apps/lightcraft) for a photo library and raw development, and [FilmCraft](/filmcraft) for a video timeline. These are separate applications with different working documents.

Do not assume a shared family name guarantees lossless project exchange. Choose a supported interchange format and validate the result in the receiving application. Keep the original editable document in its source application until that check is complete.
