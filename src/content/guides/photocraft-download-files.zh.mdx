## 查找官方下载文件

这里可按完整文件名查找 PhotoCraft 安装包，确认大小与校验值，再从官方 **storytold/photocraft** GitHub 仓库直接下载。当前下载版本为 **v%CURRENT_VERSION%**，旧版和候选版分别标注。使用浏览器的 **Ctrl+F / Command+F** 搜索文件名，例如 `photocraft-%CURRENT_VERSION%-windows-x64.msi`；文件名旁的 **#** 可定位到该文件所在行。

选择安装包请看 [Windows](/photocraft-windows)、[macOS](/photocraft-macos) 或 [Linux 指南](/photocraft-linux)；了解更新内容请看[版本历史](/photocraft-version-history)。表中也收录更新元数据和调试符号等辅助文件，最后一列说明用途。

## 核验已下载文件

先匹配**完整文件名与版本号**，包括 CPU 架构及扩展名。**1 MiB = 1,048,576 字节**；每个四舍五入的大小下方均列出准确字节数。GitHub 使用十进制 MB 时，显示值可能不同。

在 Windows 中，把下面的示例文件名替换为实际下载文件：

```powershell
Get-FileHash .\photocraft-%CURRENT_VERSION%-windows-x64.msi -Algorithm SHA256
```

macOS 使用 `shasum -a 256 <文件名>`；Linux 或已安装相应工具的 FreeBSD 使用 `sha256sum <文件名>`。逐一核对全部 64 位字符。完整操作与记录范围见[下载安全与验证指南](/is-photocraft-safe)。

本快照收录[官方 GitHub 发布 API](https://api.github.com/repos/storytold/photocraft/releases?per_page=100) 返回的全部公开版本，包括早期候选版。每组均链接到官方发布页及该版本的 `SHA256SUMS.txt`。大小取自 GitHub 资产元数据，并与下载响应字节数核对；SHA256 由脚本读取每版校验列表生成，GitHub 提供资产摘要时同时交叉比对。校验列表无法记录自身摘要，因此该文件所在行由下载到的文本内容计算，并在 GitHub 提供摘要时交叉核对。

GitHub 自动生成的**源码 ZIP / tar.gz** 不属于附加的二进制发布资产，且没有官方校验列表条目，因此不列入本表。发布资产中的 Web ZIP、FreeBSD 归档、AppImage 更新数据及安装器调试符号均已收录。文件列在这里不代表适用于所有系统；元数据核验也不等于扫描了每个二进制文件。下载均指向 GitHub，本站不重新打包文件。
